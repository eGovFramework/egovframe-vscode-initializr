# v5.1.0 릴리스 노트

- 배포일: 2026-11-26
- 패키지 버전: 5.1.0
- 이전 버전: 5.0.7 (2026-10-16)

표준프레임워크 5.1 템플릿을 적용하고, 아키텍처 점검 기능과 프레임워크 버전 선택을 추가한 버전입니다. CRUD 코드 생성기는 생성한 코드가 프로젝트 템플릿에서 고치지 않고 동작하도록 보강했습니다.

## 주요 내용

### 아키텍처 점검 (신규)

- 사이드바에 네 번째 탭인 **아키텍쳐 (Check Arch)** 를 추가했습니다. 기존 Java 프로젝트가 표준프레임워크 아키텍처 가이드를 따르는지 점검합니다.
- 빌드 도구를 실행하지 않고 빌드 파일과 Java 소스를 읽어서 판정합니다.
  - Project: 실행환경 세대(3.x / 4.x / 5.x)와 버전, 필수 라이브러리 4종(`ptl-mvc`, `fdl-cmmn`, `fdl-logging`, `psl-dataaccess`)의 적용 여부, 모듈 간 버전 일관성
  - Controller: `@Controller` 사용, 요청 매핑 어노테이션, DAO를 직접 주입받지 않는지
  - Service: `EgovAbstractServiceImpl` 상속, `@Service` 사용, Service 인터페이스 구현
  - DAO / Mapper: 구현 방식(iBatis DAO, MyBatis DAO, Mapper 인터페이스)별 기반 클래스, Bean 등록, 실행환경 세대와의 정합
- 결과를 레이어별 요약과 파일별 상세로 보여 주고, CSV 4종으로 내보낼 수 있습니다.
- 판정 규칙은 [ARCHITECTURE_CHECK.md](../reference/ARCHITECTURE_CHECK.md)에 있습니다.

### 프로젝트 생성

- 프로젝트 템플릿을 표준프레임워크 실행환경 5.1 베타가 적용된 것으로 최신화했습니다(POM의 parent 버전은 5.1.0). 이전 버전으로 제공하는 템플릿에는 실행환경 4.3.2가 적용되어 있습니다.
- **Modulith** 카테고리와 **Common Components** 템플릿을 추가해서 템플릿이 8개 카테고리의 23종이 되었습니다.
- 템플릿마다 **프레임워크 버전**을 고를 수 있습니다. 5.1.0 템플릿은 확장에 내장되어 있고, 4.3.2 템플릿(20종)은 선택했을 때 GitHub Releases에서 내려받습니다.
- 내려받은 템플릿은 VS Code 전역 저장소(globalStorage)에 버전별로 캐시합니다. 확장을 업데이트해도 캐시가 유지되고, VSIX 패키징에 섞여 들어가지 않습니다.
- 캐시를 조회하고 삭제하는 명령 **eGovFrame: Show Template Cache Info**, **eGovFrame: Clear Template Cache**를 제공합니다.

### CRUD 코드 생성

- **ERD 미리보기**를 추가했습니다. 입력한 DDL의 테이블, 컬럼, 기본 키, 외래키 관계를 다이어그램으로 표시합니다.
- DDL의 COMMENT를 VO 필드의 주석에 반영합니다.
- 타입 매핑을 보강했습니다.
  - `NUMBER`는 정밀도와 스케일에 따라 `Integer`, `Long`, `BigDecimal`로 매핑합니다.
  - `TEXT`, `BLOB`, `BYTEA` 등 누락되어 있던 타입을 `String`과 `byte[]`로 매핑합니다.
  - `DATE`, `TIME`, `DATETIME`, `TIMESTAMP`를 `java.time.LocalDate`, `LocalTime`, `LocalDateTime`으로 매핑하고 VO 필드에 `@DateTimeFormat`을 붙입니다.
- 등록/수정 화면의 입력란을 컬럼 타입에 맞게 생성합니다(숫자, 날짜, 시간, Boolean 선택란). NOT NULL 컬럼은 필수 입력으로 표시하고 저장하기 전에 브라우저의 입력 검사를 실행합니다.
- 생성한 코드가 생성 직후에 동작하지 않던 문제를 고쳤습니다.
  - Mapper XML과 JSP를 프로젝트 템플릿이 읽는 위치에 생성합니다.
  - Thymeleaf 화면의 폼 주소를 링크 표현식으로 생성해서 컨텍스트 경로가 있는 환경에서도 동작합니다.
  - 비운 입력란을 `null`로 받아 NULL을 허용하는 컬럼을 비운 채 저장할 수 있고, 비운 컬럼에는 DDL의 DEFAULT가 적용됩니다.
  - 없는 글의 수정 화면에 접근했을 때 NullPointerException 대신 안내 예외를 던집니다.

### 설정 파일 생성

- AOP 트랜잭션 설정 템플릿의 `txAdvisor`가 잘못된 메서드 호출을 생성하던 문제를 고쳤습니다.
- 트랜잭션 폼의 `READ_UNCOMMITTED` 오타를 고쳤습니다.

### 다국어

- 웹뷰 화면의 문구를 다국어 처리해서 탭의 이름과 프로젝트 탭, 코드 생성기 탭, 설정 화면의 주요 문구를 영어와 한국어로 제공합니다. 아키텍쳐 탭과 설정 탭의 입력 폼은 영어로만 제공됩니다.

### 보안

- 내려받는 템플릿 ZIP과 POM의 sha256을 확장에 기록하고, 다운로드 직후와 캐시를 사용할 때마다 대조합니다. 해시가 기록되지 않은 항목은 내려받지 않습니다.
- 다운로드 주소와 파일 이름을 화면에서 받지 않고 확장에 내장된 템플릿 목록에서 확정합니다.
- 다운로드에 https 강제, 리다이렉트 횟수 상한(5회), 응답 크기 상한(200MB), 소켓 타임아웃을 적용했습니다.

## 5.0.x에서 올릴 때 달라지는 점

| 항목 | 5.0.x | 5.1.0 |
|------|-------|-------|
| 날짜·시간 컬럼의 Java 타입 | `java.sql.Date`, `java.sql.Time`, `java.util.Date`(DATETIME), `java.sql.Timestamp` | `java.time.LocalDate`, `LocalTime`, `LocalDateTime` (`WITH TIME ZONE`은 `java.sql` 매핑 유지) |
| Mapper XML의 생성 위치 | `src/main/resources/mapper/` | `src/main/resources/egovframework/sqlmap/example/mappers/` |
| JSP의 생성 위치 | `src/main/webapp/WEB-INF/jsp/<package>/` | `src/main/webapp/WEB-INF/jsp/egovframework/example/<table>/` (패키지 이름과 무관) |
| 템플릿 컨텍스트의 컬럼 정보 | | `inputType`, `inputStep`, `dateTimePattern`, `isNotNull`, `hasDefault` 추가 |
| 프로젝트 템플릿의 실행환경 | 5.0.0 | 5.1 베타 (POM의 parent 버전은 5.1.0). 이전 버전으로 4.3.2를 선택할 수 있습니다. |

5.0.x로 생성해 둔 CRUD 코드를 5.1.0으로 다시 생성하면 VO의 날짜 필드 타입과 Mapper XML, JSP의 위치가 달라집니다. 기존 파일을 그대로 두고 다시 생성하면 이전 위치의 파일이 남으므로, 다시 생성할 때에는 이전 파일을 정리합니다. 커스텀 템플릿에서 날짜 컬럼의 `javaType` 값을 비교하는 조건이 있으면 새 타입 이름으로 고칩니다.

## 요구 사항

- Visual Studio Code 1.84.0 이상
- 4.3.2 템플릿으로 프로젝트를 생성할 때에는 GitHub에 접속할 수 있는 네트워크가 필요합니다. 그 밖의 기능은 네트워크 없이 동작합니다.

## 설치

Extensions 뷰에서 `eGovFrame Initializr in VSCode`를 검색해 설치하거나, [Marketplace 페이지](https://marketplace.visualstudio.com/items?itemName=egovframework.egovframe-vscode-initializr)에서 설치합니다. VSIX 파일로 설치하는 방법은 [설치와 설정 가이드](../setup/INSTALLATION_GUIDE.md)에 있습니다.

```bash
code --install-extension egovframe-vscode-initializr-5.1.0.vsix
```

## 참고

- 아키텍처 점검에서 필수 라이브러리의 전이 의존을 판정하는 실행환경 5.1.x 모듈 그래프는 5.1.0 베타에서 추출한 것입니다. 필수 라이브러리 4종에 도달하는 경로는 5.0.x와 같습니다.
- 생성되는 CRUD 코드는 실행환경 5.x를 기준으로 합니다(`@EgovMapper`, `jakarta.*`). 4.3.2 템플릿으로 만든 프로젝트에 넣을 때에는 해당 부분을 고쳐야 합니다.
- 문제가 있으면 <https://github.com/eGovFramework/egovframe-vscode-initializr/issues>에 알려 주세요.
